## 👋 Sobre mim

Sou **Guilherme Januário**, estudante de Engenharia de Software e uma pessoa que gosta de entender como a tecnologia funciona — e como ela pode resolver problemas reais.

Meu contato com tecnologia passa por sites, sistemas, APIs, bancos de dados e automações. Também trago vivência com atendimento ao cliente, ferramentas digitais e CRMs, que me ajuda a olhar para as necessidades de quem usa um sistema.

**Meu foco atual é aprender Java e consolidar os fundamentos de programação**, para transformar a experiência que tive com projetos em autonomia para escrever e compreender código.

## 🤖 Transparência sobre meus projetos

> **Os projetos deste portfólio foram construídos com apoio de inteligência artificial na geração e alteração do código. Ainda estou no início do aprendizado de programação e não tenho autonomia para desenvolver esses sistemas sozinho.**

Minha experiência é prática no uso de ferramentas e na condução de projetos com IA. Ter contato com uma tecnologia em um projeto **não significa dominá-la**: diferencio aqui o que estou estudando, o que já utilizei com assistência e o que faz parte do meu cotidiano.

Este portfólio registra minha trajetória de aprendizado; não é uma declaração de experiência como desenvolvedor independente nem de certificação técnica nas tecnologias listadas.

## 🚀 Projetos e experiências

### 🛍️ FKA Imports — catálogo e painel administrativo

Projeto web dividido em frontend e backend, desenvolvido com IA. Tive contato com a integração entre interface, API e banco de dados.

- **Interface:** HTML, CSS e JavaScript, com área administrativa.
- **Backend:** Node.js e Express, com rotas para produtos, autenticação, avaliações, configurações, uploads e analytics.
- **Dados e serviços:** PostgreSQL no Supabase e integração com Cloudinary.
- **Situação:** projeto sem uso atual por mim; código mantido privado.

### 🏢 Universo — gestão de terceiros

Projeto em desenvolvimento assistido por IA, com estrutura para empresas, funcionários, contratos, documentos e acompanhamento de conformidade.

- **Tecnologias presentes:** Next.js, React, TypeScript, Tailwind CSS e Supabase.
- **Contato técnico:** formulários, validação com Zod, consultas, migrações SQL, permissões e dashboards.
- **Situação:** projeto que pretendo continuar; repositório privado.

### 🌐 Ávora Assessoria — landing page

Página de apresentação e captação de contatos, construída com IA usando **HTML, CSS e JavaScript**.

- Layout responsivo, formulário com validações e integração com Google Apps Script.
- Exemplo do meu contato com interfaces e integração de ferramentas.
- **Situação:** código público; integração original precisa de revisão de segurança antes de reutilização.

[📂 Ver a documentação do projeto](https://github.com/guilhermejan/avora-assessoria)

### ⚙️ Automação para Discord

Experiência assistida com **Node.js e discord.js** em um bot de encaminhamento de mensagens entre canais. Esse projeto me colocou em contato com eventos, APIs e configuração por variáveis de ambiente.

**Situação:** código privado. Uso de automações deve respeitar as permissões dos servidores e a privacidade dos participantes.
